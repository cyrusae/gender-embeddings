# gvalnorm_es

Gender ValNorm, Spanish: do human gender ratings of objects show up in the vectors, before and after each mitigation? Includes the Omrani, orthogonal (Addendum B) and fixed-English (Addendum C) arms.

- Design and results: `docs/gvalnorm-prereg.md`
- Produced by: `scripts/gvalnorm_run.py es (then gvalnorm_omrani.py, gvalnorm_orth.py)` (see the script's docstring)
- Files: `gvalnorm_fits.csv`, `gvalnorm_fixed_en_cos.csv`, `gvalnorm_fixed_en_fits.csv`, `gvalnorm_fixed_en_verdicts.csv`, `gvalnorm_nouns.csv`, `gvalnorm_omrani_fits.csv`, `gvalnorm_omrani_info.json`, `gvalnorm_omrani_verdicts.csv`, `gvalnorm_orth_cos.csv`, `gvalnorm_orth_fits.csv`, `gvalnorm_orth_verdicts.csv`, `gvalnorm_verdicts.csv`, `info.json`
